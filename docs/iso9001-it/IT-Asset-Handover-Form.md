| **เวอร์ชัน** | 1.0 |

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้เมื่อเบิก มอบหมาย โอนย้าย หรือคืนทรัพย์สิน IT เช่น Notebook, PC, จอ, โทรศัพท์, อุปกรณ์เครือข่าย
2. ผู้รับทรัพย์สินต้องลงนามรับทราบเงื่อนไขการใช้งานและความรับผิดชอบ
3. เมื่อคืนอุปกรณ์ IT ต้องล้างข้อมูลตามขั้นตอนก่อนนำกลับคลังหรือโอนต่อ
4. รหัสเอกสารแนะนำ: `AST-YYYYMMDD-XXX`

# ส่วนที่ 4: เงื่อนไขการใช้งาน (ผู้รับทรัพย์สินต้องอ่านและยอมรับ)

1. ใช้เพื่อกิจการของบริษัทเท่านั้น ห้ามติดตั้งซอฟต์แวร์เถื่อน
2. ดูแลรักษา ป้องกันการสูญหาย และแจ้ง IT ทันทีเมื่อชำรุด สูญหาย หรือถูกขโมย
3. ไม่เก็บรหัสผ่านบนเครื่องแบบไม่ปลอดภัย และล็อกหน้าจอเมื่อไม่อยู่ที่เครื่อง
4. เมื่อพ้นสภาพงานหรือเปลี่ยนหน่วยงาน ต้องคืนทรัพย์สินพร้อมอุปกรณ์ครบภายในกำหนด
5. ข้อมูลในเครื่องเป็นทรัพย์สินของบริษัท IT มีสิทธิ์ล้างข้อมูลตามนโยบายเมื่อคืนเครื่อง
