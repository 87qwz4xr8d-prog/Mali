# รายการตรวจสอบภายในแผนกเทคโนโลยีสารสนเทศ
## IT Internal Audit Checklist

| รายการ | รายละเอียด |
|--------|------------|
| **รหัสเอกสาร** | FORM-IT-AUD-001 |
| **เวอร์ชัน** | 1.0 |
| **ข้อ ISO 9001** | 9.2 การตรวจประเมินภายใน |
| **ผู้รับผิดชอบแบบฟอร์ม** | ISO Coordinator / ผู้ตรวจประเมินภายใน |
| **การจัดประเภทเอกสาร** | ภายในองค์กร (Internal) |
| **เอกสารที่เกี่ยวข้อง** | DOC-IT-ML-001, FORM-IT-NCR-001, ขั้นตอนและนโยบายแผนก IT ทั้งหมด |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้ประกอบการตรวจประเมินภายในกระบวนการ IT ตามแผนการตรวจประจำปี
2. ผู้ตรวจต้องเป็นอิสระจากงานที่ตรวจมากที่สุดเท่าที่ทำได้
3. สิ่งพบที่เป็น Nonconformity ให้เปิด **FORM-IT-NCR-001**
4. Observation / Opportunity for Improvement ให้บันทึกในส่วนสรุปและติดตามตามความเหมาะสม
5. รหัสรอบตรวจแนะนำ: `AUD-IT-YYYY-XX`
