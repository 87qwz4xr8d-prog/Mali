# แบบฟอร์มรายงานสิ่งไม่เป็นไปตามข้อกำหนด และการดำเนินการแก้ไข/ป้องกัน
## Nonconformity Report and Corrective / Preventive Action (CAPA) Form

| รายการ | รายละเอียด |
|--------|------------|
| **รหัสเอกสาร** | FORM-IT-NCR-001 |
| **เวอร์ชัน** | 1.0 |
| **ข้อ ISO 9001** | 10.2 สิ่งไม่เป็นไปตามข้อกำหนดและการดำเนินการแก้ไข |
| **ผู้รับผิดชอบแบบฟอร์ม** | ฝ่ายเทคโนโลยีสารสนเทศ / ISO Coordinator |
| **การจัดประเภทเอกสาร** | ภายในองค์กร (Internal) |
| **เอกสารที่เกี่ยวข้อง** | FORM-IT-INC-001, FORM-IT-AUD-001, FORM-IT-CR-001, DOC-IT-ML-001 |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้เมื่อพบสิ่งไม่เป็นไปตามข้อกำหนด (Nonconformity) จากอุบัติการณ์ การตรวจประเมิน ข้อร้องเรียน หรือการทบทวนฝ่ายบริหาร
2. แยก **การแก้ไขทันที (Correction)** ออกจาก **การดำเนินการแก้ไขสาเหตุ (Corrective Action)**
3. ประเมินความจำเป็นของ **การป้องกัน (Preventive Action)** สำหรับความเสี่ยงที่คล้ายกัน
4. รหัสแนะนำ: `NCR-YYYYMMDD-XXX`
