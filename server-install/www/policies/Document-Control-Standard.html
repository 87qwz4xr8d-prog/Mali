CONTROLLED DOCUMENT — เอกสารควบคุม หากพิมพ์ออกมาถือเป็น Uncontrolled Copy เว้นแต่ระบุเป็นอย่างอื่น

1. วัตถุประสงค์

กำหนดวิธีควบคุมการจัดทำ ทบทวน อนุมัติ แจกจ่าย แก้ไข และยกเลิกเอกสารในระบบบริหารคุณภาพและการบริหารความมั่นคงปลอดภัยสารสนเทศ ให้สอดคล้องกับ ISO 9001:2015 ข้อ 7.5

2. ขอบเขต

ใช้กับเอกสารดังต่อไปนี้ขององค์กร

  1. นโยบาย (Policy)
  2. มาตรฐาน / คู่มือ (Standard / Manual)
  3. ขั้นตอนปฏิบัติ (Procedure)
  4. แบบฟอร์ม / บันทึก (Form / Record)
  5. แผนงานที่เกี่ยวข้องกับคุณภาพและความมั่นคงปลอดภัยสารสนเทศ

3. คำนิยาม

คำศัพท์ ความหมาย
Controlled Document เอกสารที่อยู่ภายใต้การควบคุมเวอร์ชันและการอนุมัติ
Uncontrolled Copy สำเนาที่พิมพ์หรือแจกนอกระบบควบคุม อาจไม่ใช่ฉบับล่าสุด
Obsolete Document เอกสารที่ยกเลิกแล้ว ต้องกันออกจากการใช้งาน
Master List ทะเบียนแม่เอกสารที่ระบุฉบับที่บังคับใช้
Record หลักฐานผลการดำเนินงาน เช่น แบบฟอร์มที่กรอกแล้ว

5. วงจรชีวิตเอกสาร

Draft → Review → Approve → Publish (Controlled)
     → Revise → Review → Approve → Publish
     → Obsolete / Archive
  1. จัดทำ (Draft) — ผู้รับผิดชอบร่างเอกสารตามแม่แบบ
  2. ตรวจสอบ (Review) — ผู้เกี่ยวข้องตรวจความถูกต้องและครบถ้วน
  3. อนุมัติ (Approve) — ผู้มีอำนาจลงนามอนุมัติ
  4. เผยแพร่ (Publish) — ขึ้นทะเบียน Master List และแจกจ่ายฉบับควบคุม
  5. ทบทวน (Periodic Review) — อย่างน้อยปีละ 1 ครั้ง
  6. ยกเลิก (Obsolete) — เปลี่ยนสถานะ กันออกจากจุดใช้งาน และเก็บถาวรตามกำหนด

6. การแก้ไขเอกสาร (Revision Control)

  1. การเปลี่ยนเนื้อหาที่มีผลต่อการปฏิบัติงานต้องออก Rev. ใหม่
  2. บันทึกประวัติการแก้ไขทุกครั้ง
  3. ฉบับเก่าต้องทำเครื่องหมาย Obsolete และถอดจากจุดใช้งาน
  4. การแก้พิมพ์เล็กน้อยที่ไม่มีผลต่อความหมาย อาจบันทึกเป็น editorial change ได้ตามที่ Document Controller กำหนด แต่ต้องมีหลักฐาน
Rev. วันที่ สรุปการแก้ไข ผู้แก้ไข ผู้อนุมัติ
00 [วันที่] ออกใช้ฉบับแรก

7. การควบคุมแบบฟอร์มและบันทึก

  1. แบบฟอร์มเปล่าเป็น Controlled Document
  2. แบบฟอร์มที่กรอกแล้วเป็น Record ต้องกำหนด
    • ผู้เก็บรักษา
    • สถานที่เก็บ
    • ระยะเวลาเก็บ
    • วิธีทำลายเมื่อครบกำหนด
  3. ห้ามใช้แบบฟอร์มนอก Master List

ระยะเวลาเก็บรักษาบันทึก (ตัวอย่าง)

ประเภทบันทึก ระยะเวลาขั้นต่ำ
บันทึกการอนุมัติเอกสาร อย่างน้อย 3 ปี หรือตามกฎหมาย
แบบฟอร์มขอยกเว้นนโยบาย อย่างน้อย 3 ปี นับจากวันปิดคำขอ
บันทึกการอบรม อย่างน้อย 3 ปี
บันทึกเหตุการณ์ด้านความปลอดภัย ตาม PROC-IR-001 และข้อกำหนดกฎหมาย

8. การแจกจ่ายและการเข้าถึง

  1. เอกสารควบคุมเผยแพร่ผ่านช่องทางที่กำหนด เช่น พอร์ทัล Server / ระบบเอกสารกลาง
  2. ระบุสิทธิ์ผู้เข้าถึงตาม Need-to-Know
  3. สำเนาพิมพ์ต้องระบุ “Uncontrolled Copy when printed”
  4. เมื่อมีการแก้ไข ต้องแจ้งผู้เกี่ยวข้องและถอดฉบับเก่า

9. บทบาท

บทบาท หน้าที่
Document Controller ดูแล Master List รหัสเอกสาร การเผยแพร่และสถานะ Obsolete
Document Owner เนื้อหาเอกสาร ความถูกต้อง และการทบทวนตามรอบ
Reviewer ตรวจสอบก่อนอนุมัติ
Approver อนุมัติให้มีผลบังคับใช้
ผู้ใช้งาน ใช้เฉพาะฉบับล่าสุดตาม Master List
