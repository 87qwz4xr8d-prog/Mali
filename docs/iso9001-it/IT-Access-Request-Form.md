## คำแนะนำการใช้แบบฟอร์ม

1. ใช้สำหรับขอเปิดสิทธิ์ใหม่ เปลี่ยนแปลงสิทธิ์ หรือเพิกถอนสิทธิ์/บัญชีผู้ใช้
2. ให้สิทธิ์ตามหลัก **Least Privilege** และ **Need-to-Know** เท่านั้น
3. สิทธิ์ชั่วคราวต้องระบุวันหมดอายุทุกครั้ง
4. สิทธิพิเศษ (Admin / Privileged) ต้องได้รับการอนุมัติจากหัวหน้า IT หรือเจ้าของระบบ
5. รหัสคำขอแนะนำ: `AR-YYYYMMDD-XXX`
