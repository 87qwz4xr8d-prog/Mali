================================================================================
  Mali — คู่มือติดตั้งบน Server (ชุดติดตั้ง)
================================================================================

ความต้องการ
  - PHP 8.2 ขึ้นไป (แนะนำ 8.2 หรือ 8.3)
  - ส่วนขยาย: pdo_mysql, mbstring, fileinfo
  - MySQL 8+ หรือ MariaDB
  - Apache (แนะนำ) หรือ Nginx

--------------------------------------------------------------------------------
วิธีที่ 1: XAMPP / Laragon (เครื่องตัวเอง)
--------------------------------------------------------------------------------

1) แตกไฟล์ ZIP นี้ แล้วคัดลอกโฟลเดอร์ Mali ไปที่
     C:\xampp\htdocs\mali
   หรือ
     C:\laragon\www\mali

2) เปิด phpMyAdmin → Import → เลือกไฟล์
     sql/schema.sql
   แล้วกด Go (จะสร้างฐานข้อมูลชื่อ mali พร้อมข้อมูลเริ่มต้น)

3) เปิดไฟล์ config/database.php แก้ค่าให้ตรงเครื่อง
     username: root
     password: (ว่างสำหรับ XAMPP ทั่วไป)

4) เปิดเบราว์เซอร์
     http://localhost/mali/public/
   หรือ
     http://localhost/mali/   (มีไฟล์ index.php นำทางไป public ให้อัตโนมัติ)

5) เข้าสู่ระบบ
     ผู้ใช้: admin
     รหัสผ่าน: admin123
   *** ควรเปลี่ยนรหัสผ่านทันทีหลังติดตั้งจริง ***

6) ตรวจสิทธิ์โฟลเดอร์อัปโหลด
     public/uploads/receipts/  ต้องเขียนไฟล์ได้

7) (แนะนำ) เปิด
     http://localhost/mali/public/setup-check.php
   เพื่อตรวจเวอร์ชัน PHP/ส่วนขยาย แล้วลบไฟล์นี้ทิ้งหลังติดตั้งสำเร็จ

อัปเกรดจากเวอร์ชันก่อนหน้า
  - Import เพิ่มไฟล์ sql/migration_txn_details.sql
    (เพิ่มฟิลด์ผู้รับ/ร้าน, ช่องทางชำระ, เลขอ้างอิง)
  - ชุดติดตั้งตั้งแต่ v1.1 รวมโฟลเดอร์ vendor/ สำหรับส่งออกรายงาน
    ถ้าโคลนจาก Git ให้รัน: composer install

รายงาน
  เมนู "รายงาน" → เลือกเดือน → PDF / Excel / PowerPoint / พิมพ์

--------------------------------------------------------------------------------
วิธีที่ 2: Shared Hosting / cPanel
--------------------------------------------------------------------------------

1) อัปโหลดไฟล์ ZIP ผ่าน File Manager แล้วแตกไฟล์
   หรืออัปโหลดเนื้อหาในโฟลเดอร์ Mali ไปที่ public_html/mali

2) ใน cPanel → MySQL Databases
   - สร้างฐานข้อมูล เช่น  user_mali
   - สร้างผู้ใช้ MySQL และให้สิทธิ์ทั้งหมดกับฐานข้อมูลนั้น

3) แก้ config/database.php
     host: localhost (หรือตามที่โฮสต์แจ้ง)
     dbname: ชื่อฐานที่สร้าง
     username / password: ตามที่สร้างใน cPanel

4) Import ฐานข้อมูล
   - phpMyAdmin → เลือกฐานข้อมูลที่สร้าง → Import → sql/schema.sql
   - หมายเหตุ: ไฟล์ schema.sql มีคำสั่ง CREATE DATABASE / USE mali
     ถ้าโฮสต์ไม่ให้สร้าง DB เอง ให้ลบบรรทัด CREATE DATABASE และ USE ออก
     แล้ว import เฉพาะส่วนสร้างตาราง + INSERT ภายในฐานที่สร้างไว้แล้ว

5) ชี้โดเมน/ซับโดเมนไปที่โฟลเดอร์ public/ (แนะนำ)
   หรือเปิด https://yourdomain.com/mali/public/

6) ตั้งสิทธิ์โฟลเดอร์
     chmod 775 public/uploads/receipts

7) Login ด้วย admin / admin123 แล้วเปลี่ยนรหัสผ่าน

--------------------------------------------------------------------------------
วิธีที่ 3: VPS / Apache DocumentRoot
--------------------------------------------------------------------------------

1) คัดลอกโปรเจกต์ไปที่ /var/www/mali
2) VirtualHost ชี้ DocumentRoot ไปที่ /var/www/mali/public
3) Import sql/schema.sql
4) แก้ config/database.php
5) chown -R www-data:www-data public/uploads
6) เปิดเว็บไซต์แล้ว login

ตัวอย่าง Apache VirtualHost:

  <VirtualHost *:80>
      ServerName mali.example.com
      DocumentRoot /var/www/mali/public
      <Directory /var/www/mali/public>
          AllowOverride All
          Require all granted
      </Directory>
  </VirtualHost>

โครงสร้างในชุดนี้
--------------------------------------------------------------------------------

  INSTALL.txt                 คู่มือนี้
  README.md                   รายละเอียดโปรเจกต์
  index.php                   นำทางไป public/
  config/database.php         ตั้งค่าฐานข้อมูล (ต้องแก้)
  config/database.example.php ตัวอย่างค่าคอนฟิก
  sql/schema.sql              สร้างตาราง + ข้อมูลเริ่มต้น
  public/                     จุดเข้าใช้งานเว็บ
  public/setup-check.php      ตรวจสภาพแวดล้อม (ลบหลังติดตั้ง)
  public/uploads/receipts/    ที่เก็บไฟล์หลักฐาน
  src/                        โค้ดหลัก PHP
  views/                      หน้าจอภาษาไทย
