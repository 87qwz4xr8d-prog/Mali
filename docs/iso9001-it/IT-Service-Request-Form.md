# แบบฟอร์มขอรับบริการเทคโนโลยีสารสนเทศ
## IT Service Request Form

| รายการ | รายละเอียด |
|--------|------------|
| **รหัสเอกสาร** | FORM-IT-SR-001 |
| **เวอร์ชัน** | 1.0 |
| **ข้อ ISO 9001** | 8.2 ข้อกำหนดของผลิตภัณฑ์และบริการ, 8.5.1 การควบคุมการผลิตและการให้บริการ |
| **ผู้รับผิดชอบแบบฟอร์ม** | ฝ่ายเทคโนโลยีสารสนเทศ (IT Service Desk) |
| **การจัดประเภทเอกสาร** | ภายในองค์กร (Internal) |
| **เอกสารที่เกี่ยวข้อง** | DOC-IT-ML-001, FORM-IT-CR-001, FORM-IT-INC-001 |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้เมื่อต้องการขอรับบริการจากแผนก IT เช่น ติดตั้งซอฟต์แวร์ แก้ปัญหาเครื่อง ขออุปกรณ์ สอบถามระบบ
2. หากเป็นเหตุขัดข้องฉุกเฉินที่กระทบการทำงาน ให้ใช้ **FORM-IT-INC-001** ควบคู่หรือแทนตามความเหมาะสม
3. หากเป็นการเปลี่ยนแปลงระบบ Production ให้ใช้ **FORM-IT-CR-001**
4. รหัสคำขอแนะนำ: `SR-YYYYMMDD-XXX` เช่น `SR-20261019-001`
