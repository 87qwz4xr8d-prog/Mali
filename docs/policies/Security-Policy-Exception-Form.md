## คำแนะนำการใช้แบบฟอร์ม

1. ใช้แบบฟอร์มนี้เมื่อไม่สามารถปฏิบัติตามนโยบาย มาตรฐาน หรือขั้นตอนด้านความปลอดภัยได้ชั่วคราว หรือต้องการผ่อนผันเป็นกรณี ๆ
2. ผู้ขอต้องระบุเหตุผลทางธุรกิจ ระยะเวลา และ**มาตรการชดเชยความเสี่ยง (Compensating Controls)** ให้ชัดเจน
3. ห้ามเริ่มดำเนินการที่ยกเว้นก่อนได้รับอนุมัติ เว้นแต่เป็นกรณีฉุกเฉินที่ได้รับอนุญาตตามขั้นตอนที่เกี่ยวข้อง และต้องส่งแบบฟอร์มตามภายหลังโดยเร็ว
4. การยกเว้นที่อนุมัติแล้วต้องทบทวนอย่างน้อยทุก **90 วัน** หรือตามวันที่กำหนดในแบบฟอร์ม
5. ส่งแบบฟอร์มที่กรอกครบถึง [ระบุ: ISO / security@company / ระบบตั๋วงาน]

**รหัสคำขอแนะนำ:** `EXC-YYYYMMDD-XXX` เช่น `EXC-20260916-001`
