# แบบฟอร์มบันทึกเหตุขัดข้อง / อุบัติการณ์ด้าน IT
## IT Incident / Problem Record Form

| รายการ | รายละเอียด |
|--------|------------|
| **รหัสเอกสาร** | FORM-IT-INC-001 |
| **เวอร์ชัน** | 1.0 |
| **ข้อ ISO 9001** | 8.5.1 การควบคุมการให้บริการ, 10.2 สิ่งไม่เป็นไปตามข้อกำหนดและการดำเนินการแก้ไข |
| **ผู้รับผิดชอบแบบฟอร์ม** | ฝ่ายเทคโนโลยีสารสนเทศ / Incident Handler |
| **การจัดประเภทเอกสาร** | ภายในองค์กร (Internal) |
| **เอกสารที่เกี่ยวข้อง** | PROC-IR-001, FORM-IT-SR-001, FORM-IT-NCR-001, FORM-IT-CR-001 |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้บันทึกเหตุขัดข้องของระบบ เครือข่าย อุปกรณ์ หรือบริการ IT ที่กระทบการทำงาน
2. หากเป็นเหตุการณ์ด้านความปลอดภัยสารสนเทศ ให้ดำเนินการตาม **PROC-IR-001** และอ้างอิงรหัสเหตุการณ์นั้นในแบบฟอร์มนี้
3. หากพบว่าเป็นปัญหาเชิงระบบซ้ำ ๆ ให้เปิด **Problem** และพิจารณา **FORM-IT-NCR-001 / CAPA**
4. รหัสแนะนำ: `INC-YYYYMMDD-XXX` หรือ `PRB-YYYYMMDD-XXX`
