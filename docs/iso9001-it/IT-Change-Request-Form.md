| รายการ | รายละเอียด |

| **รหัสเอกสาร** | FORM-IT-CR-001 |
| **เวอร์ชัน** | 1.0 |
| **ข้อ ISO 9001** | 8.5.6 การควบคุมการเปลี่ยนแปลง |
| **ผู้รับผิดชอบแบบฟอร์ม** | ฝ่ายเทคโนโลยีสารสนเทศ / Change Owner |

| **เอกสารที่เกี่ยวข้อง** | FORM-IT-SR-001, FORM-IT-BKP-001, FORM-IT-NCR-001, PROC-BCP-001 |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้ก่อนเปลี่ยนแปลงระบบ Production, โครงข่าย, ซอฟต์แวร์ธุรกิจ, หรือโครงสร้างพื้นฐานที่อาจกระทบผู้ใช้
2. การเปลี่ยนแปลงฉุกเฉิน (Emergency Change) ทำได้ตามขั้นตอนฉุกเฉิน แต่ต้องบันทึกและขออนุมัติตามภายหลังภายใน **1 วันทำการ**
3. ต้องมีแผนถอยกลับ (Rollback) และแผนทดสอบก่อนนำขึ้นใช้งานจริง
4. รหัสคำขอแนะนำ: `CR-YYYYMMDD-XXX`
