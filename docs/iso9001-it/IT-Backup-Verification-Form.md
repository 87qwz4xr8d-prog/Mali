|--------|------------|
| **รหัสเอกสาร** | FORM-IT-BKP-001 |

| **ข้อ ISO 9001** | 7.1.3 โครงสร้างพื้นฐาน, 8.5.1 การควบคุมการให้บริการ |
| **ผู้รับผิดชอบแบบฟอร์ม** | ฝ่ายเทคโนโลยีสารสนเทศ / Backup Operator |

| **เอกสารที่เกี่ยวข้อง** | PROC-BCP-001, FORM-IT-CR-001, FORM-IT-INC-001 |

---

## คำแนะนำการใช้แบบฟอร์ม

1. ใช้บันทึกผลการสำรองข้อมูลตามรอบ และผลการทดสอบกู้คืนเป็นระยะ
2. การสำรองก่อน Change สำคัญให้แนบหรืออ้างอิงแบบฟอร์มนี้ใน **FORM-IT-CR-001**
3. หากสำรองล้มเหลวหรือกู้คืนไม่ได้ ให้เปิด **FORM-IT-INC-001** และพิจารณา NCR
4. รหัสแนะนำ: `BKP-YYYYMMDD-XXX`
