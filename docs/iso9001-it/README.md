## การนำไปใช้

1. กรอกรหัสเอกสาร เวอร์ชัน วันที่อนุมัติ และชื่อผู้อนุมัติก่อนประกาศใช้จริง
2. เก็บไฟล์ต้นฉบับที่ควบคุมไว้ในพื้นที่เอกสารกลาง (Document Control)
3. แบบฟอร์มที่กรอกแล้วให้เก็บเป็นหลักฐานอย่างน้อยตามอายุที่กำหนดใน DOC-IT-ML-001
4. ทบทวนชุดแบบฟอร์มอย่างน้อยปีละ 1 ครั้ง หรือเมื่อมีการเปลี่ยนแปลงกระบวนการ

## ความสัมพันธ์กับเอกสารอื่น

- นโยบายและขั้นตอนด้านความปลอดภัย: ดูชุด `docs/policies/` (POL-ITSEC-001, PROC-IAM-001, PROC-IR-001 ฯลฯ)
- ระบบซ่อมบำรุงรถกระเช้า (Mali CMMS): ใช้สำหรับงานซ่อมเครื่องจักร ไม่แทนที่แบบฟอร์ม IT ชุดนี้
